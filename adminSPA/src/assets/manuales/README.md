# Manuales de usuario (producción)

Estos PDF se incluyen en el build de Angular (`ng build`) y se sirven desde `/assets/manuales/`.

Fuente editable (HTML + capturas): `documentacion/manual-usuario/` (carpeta local, no versionada).

Fuentes HTML (versionadas): `_src/Manual_Guia_Remision.html`, `_src/Manual_Guia_Transportista.html`, `_src/Manual_Configuracion_Facturacion_Sunat.html`.

Tras regenerar un PDF en `documentacion/` o `docs/`, cópielo aquí con el mismo nombre para actualizar producción.
