Credenciales API guías de remisión (no SOAP)

Nueva Plataforma GRE (REST): Flujo: generar XML UBL 2.1 → comprimir en ZIP → calcular hash SHA-256 → enviar por API REST.
Endpoint: POST /v1/contribuyente/gem/comprobantes/{ruc}-{tipo}-{serie}-{numero}
La URL base debe ser https://api-cpe.sunat.gob.pe (producción) o https://e-beta.sunat.gob.pe (pruebas).
⚠ No usar URL SOAP (e-guiaremision.sunat.gob.pe/.../billService?wsdl), esa es la plataforma antigua.
App Web en SUNAT: el token OAuth2 usa en la URL el ID (UUID) de la aplicación; el backend prueba ese path y también el del RUC por compatibilidad.
Solo la URL base. Producción: https://api-cpe.sunat.gob.pe
RUC que usaste para crear la app en api-seguridad.sunat.gob.pe. Si es distinto al RUC de la empresa, ingrésalo aquí. Si es el mismo déjalo en blanco.
