Programación de backups

Indica si deseas backups automáticos y cada cuánto se consideran en operación (la ejecución real la programa el servidor con Task Scheduler leyendo estos valores).

Destino local del respaldo

Carpeta en el servidor SQL donde se genera el archivo .bak (parámetro -BackupDir del script backup_sqlserver.ps1).

Copia en otro servidor o NAS

Ruta UNC o de red accesible desde el servidor SQL. El script copia los .bak con robocopy (-SecondaryBackupDir). Deje vacío si no aplica.

Ejemplo: dos barras invertidas al inicio del servidor, luego carpeta compartida. La cuenta que ejecuta el backup debe tener permisos de escritura en esa ruta.

Copia en Google Drive (rclone)

Nombre del remote y carpeta remota configurados con rclone config en el servidor. El script ejecuta rclone copy sobre los .bak (-GoogleDriveRemote).

En el servidor: instalar rclone, autenticar Google Drive una vez (rclone config), probar rclone ls gdrive:. Aquí guarda el mismo destino (p. ej. miRemote:carpeta/subcarpeta).
